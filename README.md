## Purpose ##

This project was a way for me to learn about machine learning (and Rust) through writing my own digit classifier from scratch. As it was made for educational purposes, my focus was on easy interpretablility rather than efficiency or compactness, or generalizability. I learned about network architecture, regularization techniques, activation and loss function choice, and validation methods. I was able to achieve ~98% out of sample accuracy. To test the network on your own input, change the number.png file in the input folder and do cargo run in the terminal.
